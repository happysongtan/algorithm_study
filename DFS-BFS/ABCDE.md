- 주소

## 풀이 아이디어
- 방문 여부를 판단하는 visited 선언하고, 노드끼리 연결되는 리스트를 arr로 선언, 중간에 도착 여부를 판단하는 arrive
- 노드와 갯수를 입력받고, 리스트이 크기를 입력받은 node를 기준으로 추가해준다.
- for문으로 입력받은 노드를 각 리스트에 add
- 1번부터 list를 ㅇfs에 넣어준다
- dfs애서는 깊이가 5이거나 도착여부가 true가 되면 return
- 다시 vistied를 기준으로 dfs를 실행하되 depth는 1식 증가시켜서 검증한 뒤 visited가 함수가 종료 될떄가지 false인지 확인한다

## 시간 복잡도
- O(N*2)

## 느낀점
- dfs의 구조는 이해가 되나 실직적으로 처음 문제를 만나고 구현하는데 쉽게 구조가 떠오르진 않는다.
- dfs의 구조를 활용할떄 조건을 어떻게 거는지 좀더 공부해봐야 할듯 하다.
