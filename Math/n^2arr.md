## 풀이 문제
- [주소](https://school.programmers.co.kr/learn/courses/30/lessons/87390)

## 풀이 아이디어
- 전체 배열의 크기를 구할 필요는 없이 필요한 배열의 크기 right-left+1의 크기만큼 배열 선언해줌
- 향운 k/n 열은 k%n을 기준으로 잡고 두 좌표값과 나오는 값을 계산했을떄 큰수에서 +1을 하면 도출됨

## 시간 복잡도
- O(right - left)

## 느낀점
- 처음에 접근을 n차원 배열을 선언하고 값을 넣은뒤에 원하는 값을 자르고 하나의 배열로 넣으려고 생각함
- 접근법을 도움받아서 변경한뒤 쉽게 규칙을 찾아서 코드를 구성함
