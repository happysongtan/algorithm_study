## 풀이 문제
- https://school.programmers.co.kr/learn/courses/30/lessons/70129

## 풀이 아이디어
- while문으로 1만 남았을때를 제외하고 반복문시작
- 0숫자를 카운트할 zero, 누적카운트,횟수를 저장할 변수 선언
- for문으로 0의 갯수를 카운트함
- 2진수를 10진수로 바꿔주는 함수 사용해서 카운트한 0의 갯수를 전체 길이에서 빼준뒤 변환해줌
- 해당 과정을 반복

## 시간 복잡도
- O(N)

## 느낀점
- 처음 접근을 함수로 분리해서 전부 직접 하려고 했는데 문자열 관리가 어떻게 해야하나 10진수로는 어떻게 바꿀까 고민을 많이 했는데 함수를 사용하니 편하게 풀렸음
